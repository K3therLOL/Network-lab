\chapter{Маршрутизация}
\label{ch:chap4}

В данной лабораторной работе рассматривается статистическая маршрутизация с помощью устройств IOL L3 и стандартных VPC. Целью конфигурации является обеспечение взаимодействие локальных сетей друг с другом и взаимодействие внутренних узлов c внешней сетью через маршрутизатор провайдера ISL, при сохранении использования частных ip-адресов во внутреннем сегменте. В ходе работы выполняется настройка соответствующих правил трансляции и проверяется правильность настроек с помощью утилит доступности.
